# 문제 유형 예시

**설정 → 학습 → 문제 유형 예시**에서 복수정답·순서맞추기·연결하기를 풀 수 있다. 화면의 상태만 사용하며 운영 카드, 학습 기록, 출석, SRS, 오프라인 큐에 예시 답안을 저장하지 않는다. 서버 변경 없이 동작한다. 하단바는 기존 루트 공통 바를 사용한다.

`quiz.ts`, `examples.ts`, `examples.json`은 WindowApp의 `src/modules/d3m-cards/quiz-examples/`와 동일한 계약/예시다. 변경 시 두 사본의 동일성과 양쪽 테스트를 확인한다. 고유 ID로 정확한 집합/전체 순서/일대일 연결을 채점하며, 제출 후에는 답을 바꿀 수 없다. 처음부터 풀기와 유형 전환은 응답을 초기화한다.

현재 운영 DTO/문제 생성/배포와는 연결하지 않는다. 실제 운영에 추가하려면 버전 있는 문제·응답 저장 계약, 서버 검증, 구버전 호환, 최초 응답과 SRS 연결을 별도로 구현해야 한다. 기존 단일 `answer_index`에 다중 정답을 끼워 넣지 않는다.

검증: `npm test -- --runInBand`, `npm run typecheck`. SDK 52 웹 번들을 내보낸 뒤 `npm run test:ui -- <web-export>`로 유형별 정답/오답, 미완성 제출, 잠금/초기화/연결 재지정과 하단바를 함께 확인한다. 네이티브 빌드는 기존 릴리스 절차를 따른다.
