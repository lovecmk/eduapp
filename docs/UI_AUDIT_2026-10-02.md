브라우저 검사는 Windows의 Edge를 사용한다. 다른 OS에서는 먼저 `npx playwright install chromium`으로 검사 브라우저를 설치한다.
브라우저 검사 도구는 Node 20 이상을 사용한다(현재 CI/점검 환경도 Node 20/22).
목업 번들은 검사 전용이며 운영 배포에 쓰지 않는다. 자동 검사는 외부 네트워크 요청을 차단한다.

## 반영 방식

이 저장소의 기존 규칙대로 main push가 웹/APK/OTA 작업을 시작한다.
웹 배포만 버전 파일 기록 커밋(`[skip ci]`)을 생성한다. APK/OTA는 같은 원본 커밋에서 같은 다음 버전을 계산하고 별도 버전 커밋을 push하지 않는다.
APK 태그/릴리스는 기존 빌드 워크플로가 생성한다. Tauri 저장소의 태그 전용 릴리스 규칙을 이 저장소에 적용하지 않는다.
배포 전 전체 Jest 검사를 웹 워크플로에 추가했다.
