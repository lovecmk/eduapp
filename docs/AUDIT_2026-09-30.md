## 3. 목업 전용 · 미연결 — 기록만 한 것

실서버 모드에서의 동작을 기준으로 적는다. "해야 할 일"은 서버 또는 제품 결정이 필요하다.

### 3-1. 서버 API 가 없어 기기 안에서만 도는 기능

| 기능 | 지금 실서버 모드 동작 | 끝내려면 |
|---|---|---|
| **고객센터 문의** | `POST /inner/api/v1/support/inquiries` 로 보내고, 라우트가 없으면 "창구가 아직 열리지 않았어요"를 정직하게 안내 | 서버 라우트 + 콘솔 목록(docs/API_CONTRACT §6-5) — **법적 고지가 1차 창구로 안내하므로 우선순위 높음** |
| 알림 삭제 | 지운 id 를 기기에 기억해 걸러 낸다. 기기를 바꾸면 다시 보인다 | `DELETE /inner/api/v1/notifications/:id` 또는 숨김 플래그(§6-4) |
| 자랑 피드(트로피룸 '오늘의 플렉스') | 이 기기에서 올린 카드만. 화면에 그렇게 적는다 | 피드 업로드·조회·리액션 API(`uploadShareCard` 한 곳만 바꾸면 되게 짜여 있다) |
| 현장 팁(카드 상세) | 내 팁만, 이 기기에만. 화면에 "이 기기에만 저장돼요" | 팁 CRUD API |
| 체감 난이도 투표(카드 상세·학습 중 질문) | 내 선택만 기기에 남고 분포는 "준비 중" | 투표 집계 API. 난이도 데이터는 출제 편성(daily_plan)에도 쓸 수 있는 값이다 |
| 진영(faction) 선택 | 기기에만 저장 — 기기를 바꾸면 다시 고른다. 대항전 점수는 서버 community 스냅샷에서 온다 | 계정 설정(`/inner/api/v1/settings`)에 진영을 싣는 것이 가장 싸다 |
| 이벤트 쿠폰(가챠 코드) | 코드 표(`WELCOME` 등 4개)가 **앱 번들에 들어 있고** 쿠폰 화면이 목록까지 보여 준다. 교환은 로컬에서 팩을 더한 뒤 도감 동기화로 서버에 올라간다 | `POST /inner/api/v1/gacha/redeem` 서버 검증. 카드 수집이 베타(기본 꺼짐)인 동안은 노출이 좁다 |
| 카드 작성(author-card) | 목업 모드에서만 학습 목록에 병합. 실서버로는 보내지 않는다. 입구는 개발자 화면·목업 콘솔뿐 | 문제 등록은 운영 콘솔(mybrdg)이 맡는다 — 앱 쪽은 개발 도구로 두는 것이 맞아 보인다 |
| 날씨(홈 배경 효과) | 목업 '맑음'으로 폴백 | `WeatherRepository` 구현(주석에 예정으로 적혀 있음) |
| Q&A · 계정 설정 동기화 | 라우트 미배포 → 목업 폴백(개발자 화면 '연결 상태'에 표시) | 서버 라우트 배포(ARCHITECTURE.md 표 참고) |

### 3-2. 저장·동기화는 되지만 앱 어디서도 읽지 않는 값

| 값 | 상태 | 판단 필요 |
|---|---|---|
| 관심 분야(`interests`, 설비·시설 12종) | 설정에서 고르고 계정 설정으로 동기화된다. **소비처가 없다.** 카드 대분류(4종)와 대응표가 없어 통계·출제에 쓸 수 없었다 | 출제 편성에 반영할지, 대응표를 만들지, 항목을 뺄지 |
| 알림 세부 설정 `reviewAlerts` · `weeklyReport` · `inApp` · `email` | 계정 설정 모델·동기화에만 있고 UI·소비처 없음 | 쓰지 않을 거면 모델에서 정리 |
| `flexPromptEnabled` | 스위치를 뗐다(CTA 비활성). 값은 계정 설정으로 계속 동기화 | 학습 완료 자랑 CTA 를 되살릴 때 스위치도 함께 |

### 3-3. 목업 모드에서도 보이지 않는 시드

- 현장 팁 시드 5건의 `cardId` 가 `c1`·`c3`·`c7`·`c9` 인데 시드 카드 id 는 `lc001…` 형식이라
  어느 카드에도 붙지 않는다(내용도 현재 카드와 주제가 다르다). 목업 시연에 쓰려면 id 를 맞추거나 지울 것.

### 3-4. 의도적으로 실서버에서 막혀 있는 것(결함 아님)

- 회원가입 · 비밀번호 찾기 · 이메일 인증 · 간편 로그인 — 계정은 브릿지가 쥔다(README). 실서버 모드에서는
  버튼 대신 "브릿지(bridge.kfpa.or.kr)에서 진행"을 안내한다.
- QR 명함 — 비활성(코드는 주석으로 보존).
- 관리 콘솔(admin) — 목업 데이터 개발 도구. 실서버 모드에서는 '브릿지로 옮겨 갔다' 안내만.
